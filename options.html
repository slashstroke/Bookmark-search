Bookmark Search

Thanks for installing! Press Ctrl+Shift+F to open it. One optional setting is below: website icons are off until you turn them on.

Website icons

Off by default. When on, the hostname of each bookmarked site (for example github.com) is sent once to DuckDuckGo's icon service to download its icon, which is then saved on this device. Nothing else is sent, and local or private addresses are never sent. You can also withdraw this in about:addons under Permissions and data.

How to use

  • Press Ctrl+Shift+F (change it in about:addons: gear icon, then Manage Extension Shortcuts).
  • Type words to search everything. Fuzzy matching works: ggl finds Google.
  • Type a folder name and / to open it, like tools/ or tools/dev/. Words after the last / search inside it.
  • Enter opens a bookmark or enters a folder. Ctrl+Enter new tab, Shift+Enter background tab.
  • Ctrl+Shift+Enter on a folder opens everything in it. Ctrl+D saves the current page into the folder.
  • ← goes up a level. In the address bar, type b, a space, then the same kind of text.
